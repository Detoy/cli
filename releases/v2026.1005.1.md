# Vibgrate CLI 2026.1005.1

_Released 2026-10-05_

This release of the Vibgrate CLI introduces several new features and fixes that enhance the scanning and reporting capabilities. Key improvements include better handling of vulnerabilities and license findings, as well as enhanced documentation for SBOM exports.

## What changed

### New

- `vg scan --baseline` now records findings that match the baseline, including a detailed JSON output.
- `vg scan --vulns --format json` now includes additional fields like `epss`, `epssPercentile`, and `kev` when available.
- `vg scan --vulns --offline --package-manifest` documents the local manifest shape and ensures consistent findings order.
- `vg scan --junit <file>` generates a deterministic JUnit XML report alongside other formats.
- `DOCS.md` now lists various command messages and the next command for each.

### Improved

- `vg sbom export` documentation now clarifies how resolved versions are identified.
- `vg scan --vulns --format sarif` now writes one result per package and advisory, improving clarity.

### Fixed

- `vg scan` and `vg report` correctly indicate when a vulnerability has a fix available.
- Direct Go modules without a `v` version are now handled correctly in the code graph.
- License findings in JSON and SARIF now include the repository path of the manifest when recorded.

### Security

- Sensitive information is now redacted from registry and upload error messages.
