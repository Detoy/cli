# Vibgrate CLI 2026.1006.2

_Released 2026-10-06_

This release of the Vibgrate CLI introduces several improvements and fixes, enhancing the usability and reliability of the vg command. Notable updates include better documentation for key commands and new features for risk assessment.

## What changed

### Improved

- Documentation for `vg build --attest` and `vg build --verify` is now available, detailing the signing process and error messages.
- `vg sbom export` and `vg scan --format json` now document package digest fields, clarifying project and solution identifiers.
- Documentation now explains how `vg build` records a GitHub Actions `uses:` pin in the code map.

### Changed

- `driftBudget` now accepts `maxRiskScore` and `maxRiskWorseningPercent`, with local scans reporting limits as not evaluated.
- `vg scan --summary-out` writes a JSON summary of the DriftScore for CI steps, with new outputs for drift-score, risk-level, and score-delta.

### Fixed

- `vg evidence` and `vg build --attest` now provide clear error messages when output files cannot be serialized or written.
- `vg sbom export` correctly keeps one component for multiple projects resolving the same package, with warnings for dropped dependencies.
